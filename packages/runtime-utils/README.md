Small utilities shared by Netlify packages that need to run across environments (Node.js, Deno, edge, browser), such as
reading environment variables and base64 encoding.

This is used internally by packages like [`@netlify/blobs`](https://npmx.dev/package/@netlify/blobs) and
[`@netlify/cache`](https://npmx.dev/package/@netlify/cache). You probably don't need to install it directly.
